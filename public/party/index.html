Your Photos & Data

Photos, entries and votes are stored on the server running this website. During the local preview, that storage is on the host’s computer. When the site is hosted online, it uses the host’s server storage.

The party gallery is private outside scheduled event hours. Only published winners are on display.

Other photos stay in private yearly archives for the host to manage. The host can download a backup of the photos and contest data. Uploaded photos are not added to GitHub or posted to Facebook by this site.
